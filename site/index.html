Get the code

Choose where your tile will live.

Paste this where the tile should appear. It follows every change you make in the Studio, including colours, hands and size. Load the script once per page, however many tiles you use.

Load the bundle from the CDN, then write the element anywhere in your page. Anything that renders HTML can use it, with no build step.

Prefer npm? Install straight from GitHub and import it once:

<script type="module"
  src="https://cdn.jsdelivr.net/gh/ShazMoghaddam/bezel@v1.0.0/dist/bezel.min.js"></script>

<bezel-clock variant="relief"></bezel-clock>
npm install github:ShazMoghaddam/bezel

// then, once in your app
import 'bezel-tiles';

Open this link on the screen you want to use. It shows the tile you made in the Studio full screen, keeps the screen awake, and nudges the tile a few pixels each minute to protect against burn-in. On an iPad, add it to the Home Screen for a chrome-free display.

Open display

Install Übersicht, then copy the widget folder from this repository into its widgets folder. Edit the TILES list in index.jsx to place tiles; the entry below matches the tile in the Studio. Calendar feeds are read with curl, so private Google, iCloud and Outlook feeds work.

cp -R ubersicht/bezel.widget \
  ~/Library/Application\ Support/Übersicht/widgets/

Bezel

Open-source web components · v1.0

Seven tile faces drawn entirely in vectors, so they stay crisp from a 120 px widget to a 4K desk display. Restyle every colour, frame and font, then drop one line of HTML into any site, an old iPad, or your Mac desktop.
