Clocks, calendars and weather, sharp on every screen.

Seven tile faces drawn entirely in vectors, so they stay crisp from a 120 px widget to a 4K desk display. Restyle every colour, frame and font, then drop one line of HTML into any site, an old iPad, or your Mac desktop.

Three ways to use it

The same tiles, wherever you want them to live.

Website or app

One script tag

Load the bundle, then write the element. Works with plain HTML, React, Vue, Svelte or anything that renders HTML.

<script type="module"
  src="https://cdn.jsdelivr.net/gh/ShazMoghaddam/bezel@v1.0.0/dist/bezel.min.js"></script>

<bezel-clock variant="relief"></bezel-clock>
Desk display

Any spare screen

Open a display link on an old iPad, phone or monitor. It fills the screen, keeps it awake, and nudges the tile a few pixels each minute to protect against burn-in.

/bezel/site/display.html
  ?tile=clock&variant=numerals&theme=cobalt
macOS desktop

Übersicht widget

Copy the widget folder into Übersicht and edit one config block to place tiles on your desktop, with calendar feeds read straight from disk.

cp -R ubersicht/bezel.widget \
  ~/Library/Application\ Support/\
